# Prototype — 라이브클래스 회원탈퇴 모달

라이브클래스 회원탈퇴 플로우 프로토타입입니다. 단일 HTML 파일(HTML/CSS/JS)로 동작합니다.

## 보기

- [withdrawal-v3.html](withdrawal-v3.html) 파일을 내려받아 브라우저로 열면 됩니다.
- 좌측 상단 탭으로 두 가지 케이스를 전환할 수 있습니다.
  - **사이트 여러 개 (16개)**: 부분 탈퇴 / 전체 탈퇴(계정 삭제) 분기, 목록 정렬·스크롤 확인
  - **사이트 1개 (계정 삭제)**: 마지막 사이트 탈퇴 = 계정 삭제 케이스

## 주요 동작

- 가입 사이트별 개별 선택 → 전체 선택 시 라이브클래스 계정까지 삭제
- 수강 중인 유료 클래스 보유 사이트를 목록 상단 고정(최근 가입일 순)
- 탈퇴 사유 설문 → 확인 → 접수 완료의 3단계 플로우

> 더미 데이터로 구성된 디자인 프로토타입입니다. 실제 데이터·API와 연결되어 있지 않습니다.
